# Documentación de diseño

Los archivos originales de análisis y diseño se encuentran en la raíz de `C:\changosgames` y se usaron como fuente de la implementación:

- `ChangosGamesSRS (2).pdf` — especificación de requisitos (RF-01 a RF-12, SP-01 a SP-7).
- `Diagrama_de_caso_de_uso_de_ChangosGame_corregido.pdf` — actores y casos de uso.
- `Diagrama de clases de ChangosGame (3).pdf` — entidades, atributos, operaciones y enumeración `estados`.
- `Diagrama de actividades de ingresar productos.pdf` — alta de productos.
- `Diagrama de actividades de las cuentas.pdf` — creación de cuentas e inicio de sesión.
- `diagrama_de_actividades.pdf` — flujo de consulta, reserva, entrega, venta y cancelación.
- `Diagrama de estados.pdf` — estados de la venta/reserva.

 Cuando se decida versionar la documentación, copiar los PDF a esta carpeta. No se movieron ni modificaron los originales.
